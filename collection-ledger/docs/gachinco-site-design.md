# ガチん娘 所持ライブラリ

更新日: 2026-09-28

## 目的と対象

サイトキーは `gachinco`、画面表示は「ガチん娘」。定時回収の PM2 ジョブは作らず、手動でカタログ、サムネイル、所持動画を登録し、既存のブラウザで一覧・再生する。

主カタログは Shiitake Taicho の [maker 42](https://shiitake-taicho.com/maker/42/) 全47ページ。補足カタログは a-up の [series 28772](https://www.a-up.info/avlady/series/index.php?ss=28772&pg=1) 全12ページと Neo Adult Movie Revolution のガチん娘一覧全77ページ。主サイトのタイトル、詳細URL、画像を優先し、各ソースの掲載行は別々に記録する。販売サイト固有の `st...` 番号は作品照合のIDに使わない。

セット掲載はセット全体を1作品として数える。たとえば a-up の「今日のガチん娘ちゃん。6、実録ガチ面接266」と「実録ガチ面接273、実録ガチ面接274」はそれぞれ1作品。構成する番号を含む動画ファイルは、明示されたセット作品に複数の所持ファイルとして紐付ける。タイトルが重複する異なる掲載作品は自動統合しない。

作品認識IDは `gachi0001` から始め、初回は作品タイトル順に付与する。以後追加した作品には末尾の次番号を付け、既存の番号を変更しない。各所持動画のファイル名は変更しない。

## ストレージ

走査するローカルドライブは D/E/F/G/H/I/J/K/L/N/P/Q/R/T。S は対象外。特に次の指定場所はサンプルであり、同時に走査対象でもある。フォルダの最深部まで各動画ファイルを調べる。

- `G:\all\お気に入りD(F)\購入\20180502 ガチん娘`
- `G:\all\お気に入りD(F)\新規DL\ガチん娘`
- `F:\all\保存E(H)\お気に入り\ガチん娘`
- `H:\all\保存`

照合単位は動画ファイル。出演者名ではなくタイトルを使う。`gachi`、`gachinco`、`heydouga-4037` はガチん娘の手掛かりだが、`4037` の数字単独は手掛かりにしない。親フォルダ名だけの根拠で作品を確定しない。

作品を一意に特定し、ガチん娘のファイル名上の根拠もある動画は同じドライブの `?:\uncen\gachinco` へ置く。ガチん娘のファイル名上の根拠はあるが作品不明の動画は `?:\uncen\gachinco\unmatched` へ置く。ファイル名上の根拠がなく、タイトルだけが一致する動画やフォルダ名だけが候補の動画は元の場所に残してCSVへ元パスを記録する。同名の複数実ファイルは別々の所持として記録し、上書き・重複削除をしない。

既存の uncen/FC2 などに登録済みのファイルは移動、リネーム、変更を一切しない。移動直前にもDB上の既登録パスと保存場所を再確認する。既存サイトの運用と矛盾する場合は処理を止める。
