# Night24 所持ライブラリ設計

更新日: 2026-09-27

## 目的

既存の Collection Ledger のサイト選択ドロップダウンに night24 を追加し、全作品のマスター一覧、所持状況、ローカルサムネイル、所有ファイルの再生・オープンを同じ画面構成で扱う。新規取得の常駐ジョブは作らず、必要時に手動バッチでカタログ更新、サムネイル取得、所持ファイル登録を行う。

## 対象カタログ

次の3ページ群を、各ページを巡回する手動取得対象とする。

- Analers Delight: https://analersdelight.com/moromie-av-matome/（1ページ）
- HeyDouga provider 4044: provider_4044_1 から provider_4044_10（10ページ）
- Shiitake Taicho maker 87: page=1 から page=26（26ページ）

2026-09-27 の取得では、ソースレコード1,767件（Analers 572、HeyDouga 434、Shiitake 761）を取得した。タイトル完全一致と、確認済みの4シリーズ番号ルールでまとめた内部マスター候補は1,165件となった。これは正規化規則に基づく件数であり、実作品数の人手確定を意味しない。各ソースの生レコードと由来ページを別々に保存する。

表示名は、実際にローカル保存できたサムネイルと同じソースレコードのタイトルを使う。第一候補の画像取得に失敗したときは同作品グループ内の別ソースへ順番に切り替え、成功したレコードのタイトル・画像URLを採用する。

## 所持ファイルの照合

調査対象はローカルストレージ D/E/F/G/H/I/J/K/L/N/P/Q/R/T。ユーザー指定によりクラウドの `S:` は走査・移動・DB登録の全工程で除外する。

2026-09-27 の全動画形式走査では、14ドライブ上の動画ファイル47,657パスを確認し、読み取りエラーは0件。Night24の名前または保存場所に関連する候補760パスを抽出した。前の734件という候補数は、追加の動画拡張子を対象外にしていた古い走査結果のため、この走査結果で置き換える。

| 照合結果 | 候補パス | 初期処理 |
| --- | ---: | --- |
| カタログID一致 | 213 | 同一ドライブの ?:\uncen\night24 へ移動し、所持DBへ登録 |
| カタログタイトルが一意一致 | 168 | 同上 |
| タイトルが複数作品に一致 | 0 | ファイル名にNight24表記があれば移動のみ。候補タイトルを未照合表に保存し、一覧には出さない |
| Night24表記のみで作品未特定 | 298 | ファイル名にNight24表記がある149パスは、各ドライブの`uncen\night24\unmatched`へ同一ドライブ移動し、未照合表へ記録。フォルダ名だけの149パスはCSVで人手確認 |
| 以前からのsiterip 81件 | 81 | 同一ドライブの`uncen\night24\unmatched`へ移動し、未照合表へ追加。所持DBとブラウザ一覧には登録しない |

照合結果は排他的に分類してあり、合計760パス。初回の所持処理時のdry-runでは611行が承認対象になり、そのうち81件は既に同一ドライブの`uncen\night24`直下にあり、残り530件が移動予定として出力された。実行時には同名衝突、ファイル変更、直近10分以内の更新などの事前確認で個別に保留される場合がある。

760は名前・ID・保存場所の根拠で抽出したファイルパス数であり、重複を除いた作品数でも、最終的な所有確定数でもない。複数ファイルが同じ作品を示す可能性がある。ファイル名・保存場所だけの判断、同名衝突、検索時点の実体状態などを含むため、レビューCSVと実行結果を別々に保存する。以前の106件を全体数として扱わない。

フォルダ名だけが根拠の候補は既定では `move_approved`=no とする。例えば K:\Night24 にある Noisy_Japanese.wmv は、フォルダ名だけではNight24作品と断定できず、今回の自動処理対象から除外される。

ファイル名は変更しない。作品を特定して所持登録する動画は同一ドライブの`?:\uncen\night24`直下へ、未照合動画は同一ドライブの`?:\uncen\night24\unmatched`へ置く。既存の同名ファイルがあるときは上書きせず、その行を衝突として残す。ファイルが走査時から変化している場合や直近10分以内に更新された場合も移動しない。別ドライブ間移動は行わない。

CSVで照合保留の候補が出た場合、同じ行の `classification` を manual_confirmed、`movie_code` を候補の正規コード、`move_approved` と `register_owned` を yes にして手動バッチを再実行できる。DBに存在する作品コードかを再確認してから所持テーブルへ登録し、未照合状態を解決済みにする。

## DBとブラウザ

追加するDBオブジェクトは cl スキーマのNight24専用テーブルとViewで、TM / TL / VQ の命名規約に従う。既存テーブルの削除や破壊的変更は行わない。

- `night24_tm001_master`: ブラウザ表示用マスター
- `night24_tm002_owned_files`: 作品特定済みの所有動画
- `night24_tm003_master_source_records`: ソース別ID、タイトル、URL、取得元ページ
- `night24_tm005_unmatched_files`: 作品未特定で人手確認が必要な動画
- `night24_tm007_thumbnail_assets`: 画像取得状態、保存先、再試行回数
- `night24_tm011_owned_file_video_metadata`: 動画再生情報の取得状態
- `night24_tm012_recognition_ids`: Night24 Completion画面の作品確認ID（`ngt001`形式）と内部`movie_code`を結ぶ固定対応表。初回はタイトル順で採番し、既存IDは変えず、新規作品は最大番号の次を割り当てる。
- `night24_tl001_file_process_logs`: 手動移動・登録の履歴
- `night24_tl002_master_collect_runs` / `night24_tl003_master_page_logs`: カタログ取得の実行・ページ履歴
- `night24_vq001_library_items`: 所持動画一覧
- `night24_vq002_completion_items`: 所持・未所持の全作品一覧
- `night24_vq003_thumbnail_assets`: API向けサムネイル情報

サイト選択は既存の cl.site_master APIとフロントエンドの選択UIを使用する。night24 の行とAPI source registryのView名で既存ドロップダウンへ接続する。所有動画のブラウザ再生は既存の許可パス検証とローカルプレイヤーを使用する。

サムネイルは `storage/thumbnails/night24/master` へ保存する。取得先ホストをコード内で限定し、HTTPS、画像署名、10MB上限を検査する。1作品につき最大3回の取得記録で止め、無限リトライはしない。

## 手動バッチ

- `apps/jobs/night24-recognition-id.js`: Night24の固定ID割当計画をdry-run CSVで確認し、その完全一致を確認した計画だけDBへ適用する。動画ファイルの移動・リネームは行わない。
- `ops/batches/night24_catalog_apply.bat`: 全カタログ巡回、dry-run表示、SQL追加、DB同期、サムネイル取得、件数表示
- `ops/batches/night24_owned_review.bat`: 許可されたローカルドライブ（D/E/F/G/H/I/J/K/L/N/P/Q/R/T、S除外）の全動画走査とレビューCSV作成
- `ops/batches/night24_owned_apply.bat`: レビューCSVで承認された同一ドライブ移動と、作品特定済みファイルのDB登録
- `apps/jobs/night24-unmatched-reorganization.js`: 対象CSVで明示された未照合ファイルを同一ドライブの`unmatched`へ整理し、未照合DBと移動履歴を更新する。既定はdry-runで、実行時は`--apply`を付ける。

定期スケジューラやPM2ジョブは追加しない。各バッチは.envのDB接続情報を参照する。ファイル移動とDB登録は別処理とする。移動前にfsync済みの意図をJSONLジャーナルへ記録し、移動直後にも完了行を追加する。結果CSVの保存前に停止しても、同じCSVの再実行時に元パス・先パス・サイズ・更新日時を照合してDB登録を再開できる。サムネイルはハッシュと出典を持つ`intent.json`を画像移動前に保存し、DB更新をトランザクション化する。DB更新前に停止した画像はマニフェスト検証後に再利用し、記録のない既存画像は上書きせず保留する。





## 今回の実装結果（2026-09-27）

- 37ページを同期し、`night24_tm001_master`に1,165件、`night24_tm003_master_source_records`に1,767件を登録した。1,165件はタイトル・確認済みシリーズ番号ルールでまとめた内部候補数であり、人手で確定した実作品数ではない。
- 初回の所持処理では、760候補のうちCSVで承認された611件について、530件を移動し、同一ドライブの`uncen\night24`直下にあった81件は追加移動なしで処理した。移動失敗、別ドライブ移動、リネームは0件。その後、未照合230件を`unmatched`へ整理した。
- 所持ファイル381件を`night24_tm002_owned_files`へ登録した。ファイル名マーカー149件と旧siterip 81件の計230件は、現在は各ドライブの`uncen\night24\unmatched`に元のファイル名のまま配置している。149件は既存の`night24_tm005_unmatched_files`行のパスを更新し、81件はreason=`legacy_siterip_move_only`で追加して、合計230件をstatus=`review_required`で管理する。全230件を所持DB・ブラウザの所持一覧から除外している。ドライブ別件数はF:86、G:9、H:2、J:18、K:109、N:4、P:2。フォルダ名だけの149件は移動せず保留。
- サムネイル1,165件を取得し、`night24_tm007_thumbnail_assets`に登録した。取得失敗0件、一時ファイル0件。
- 通常のCollection Ledger画面（`http://127.0.0.1:5173/?source=night24`）でドロップダウン選択、所持一覧、全作品一覧への切替を検証した。ブラウザスモークはコンソールエラー0件、失敗HTTP応答0件。
- ブラウザの作品カードから`Open file`を実行し、APIの成功応答とMPC-BEへの対象動画引き渡しを確認した。`K:\uncen\night24\321.wmv`は`ffprobe`でWMV動画・WMA音声ストリームを読み取れた。

検索・移動・登録対象からはユーザー指定により`S:`を除外した。カタログ取得やサムネイル取得の常駐PM2ジョブは追加していない。
